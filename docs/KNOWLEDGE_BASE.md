## 1️⃣ opening-rules.md (前 30s 黄金法则)

### 核心要点

**黄金 5 秒法则**:
- 第 1 秒:画面冲击或悬念抛出
- 第 3 秒:核心冲突或身份反差建立
- 第 5 秒:观众必须产生"接下来会怎样"的好奇心

**前 30s 必须完成**:
1. 建立核心冲突或悬念
2. 展示主角处境
3. 抛出第一个钩子

### 6 种开场模板

| 模板 | 适用题材 | 萌宠适配度 |
|---|---|---|
| ① 直接打脸型 | 战神归来 / 励志 | ⭐ 弱 (猫不打脸) |
| ② 身份反转型 | 萌宝 / 都市 | ⭐⭐⭐ **强适配** — "YouKei 看似普通实则是家里老大" |
| ③ 极端困境型 | 重生 / 末日 | ⭐ 弱 |
| ④ 倒叙悬念型 | 悬疑 / 古装 | ⭐⭐ 中等 |
| ⑤ 高甜钩子型 | 甜宠 / 霸总 | ⭐⭐⭐ **强适配** — "蹭脸瞬间" |
| ⑥ 重生起始型 | 重生 / 战神 | ❌ 不适用 |

### 我们的用法

- **EP01 (搬家日)**: 用 ⑤ **高甜钩子型** — "猫在箱子里探头发呆 + 主人惊讶脸"
- **EP05 (洗澡)**: 用 ② **身份反转型** — "主人想洗猫, 结果被猫泼一脸水"
- **EP12 (冬至)**: 用 ⑤ **高甜钩子型** — "猫偷面团 + 主人假装追"
- 末 3s 钩子一律用 **悬念钩** (借鉴 hook-design.md 类型①)

### 反例 (禁止的开场)

- ❌ 大段旁白介绍背景
- ❌ 慢节奏风景空镜
- ❌ "从前有个人叫xxx" 式平铺直叙
- ❌ 多角色同时出场导致信息过载

## 2️⃣ rhythm-curve.md (节奏曲线 + 单集微结构)

### 核心要点

**单集微结构** (1-3 分钟):
```
前 30s:  钩子段 — 承接上集 + 抛本集冲突 + 建立基调
中 1-1.5min: 冲突升级段 — 递进式场次
末 30s:  爽点/钩子段 — 释放爽点 + 制造下集期待
```

**全剧节奏四段** (60 集模板):
| 阶段 | 占比 | 高潮强度 | 频率 |
|---|---|---|---|
| 起势段 | 前 15% | ★★ | 每 2-3 集一个小高潮 |
| 攀升段 | 15%-45% | ★★★ | 每 5-7 集中高潮 |
| 风暴段 | 45%-80% | ★★★★ | 每 3-5 集大高潮 |
| 决战段 | 最后 20% | ★★★★★ | 几乎每集都高潮 |

### 萌宠剧适配 (12 集)

由于我们只有 12 集一季,直接按比例缩:

| 阶段 | 集数 | 占比 |
|---|---|---|
| 起势段 | EP01-02 | 17% |
| 攀升段 | EP03-06 | 33% |
| 风暴段 | EP07-10 | 33% |
| 决战段 | EP11-12 | 17% |

### 加速节奏的手段

| 手段 | 我们的用法 |
|---|---|
| 短场次快切 | EP05 洗澡 (5 个 shot 快切) |
| 多线交叉叙事 | ⚠️ 萌宠剧难用,跳过 |
| 对话加速 | EP09 外出 (猫在猫包里叫) |
| 倒计时设置 | EP11 生病 (打喷嚏 → 查百度) |
| 连续反转 | EP08 朋友来访 (过敏 → 反蹭) |

### 减速节奏的手段

| 手段 | 我们的用法 |
|---|---|
| 双人对话场景 | EP02 第一夜 (主人抱猫讲故事) |
| 独处/回忆 | ⚠️ 猫不回忆,跳过 |
| 日常生活片段 | EP06 加班夜 (猫趴键盘日常) |
| 风景/环境描写 | EP03 阳台 (鸟 + 城市背景) |

### 节奏自检清单

写完每 5 集后:
- [ ] 这 5 集的情绪曲线有起伏?
- [ ] 每集都有 ≥1 个新信息或新进展?
- [ ] 没有连续 2 集 "信息真空"?
- [ ] 高潮点之间间隔 ≤5 集?
- [ ] 喘息段也在推进剧情?

### 我们的用法

- **Writer 注入**: 每集 EP-N 必注入本文件
- **Critic 评分**: "节奏" 维度主要参照此文件

## 3️⃣ hook-design.md (钩子设计)

### 5 类钩子

| 类型 | 一句话 | 萌宠剧主钩子占比 |
|---|---|---|
| ① **悬念钩** | 抛出关键疑问, 答案留到下一集 | 25% |
| ② **反转钩** | 最后一刻颠覆观众预期 | 20% |
| ③ **情绪钩** | 把情绪推到最高点然后切断 | 30% (萌宠剧核心) |
| ④ **信息钩** | 透露改变全局的关键信息, 但只说一半 | 15% |
| ⑤ **危机钩** | 突然出现重大危机或威胁 | 10% |

### 分阶段钩子配置

**短剧 (12 集) 萌宠版**:

| 阶段 | 主钩子 | 副钩子 | 强度 |
|---|---|---|---|
| 起势 (EP01-02) | 悬念钩 / 情绪钩 | 信息钩 | 中等 |
| 攀升 (EP03-06) | 悬念钩 / 情绪钩 / 反转钩 | 信息钩 | 中等偏强 |
| 风暴 (EP07-10) | 反转钩 / 危机钩 / 信息钩 | 情绪钩 | 强 |
| 决战 (EP11-12) | 危机钩 / 反转钩 / 情绪钩 | 悬念钩 | 最强 (EP11 强, EP12 无钩子收束) |

### 钩子叠加规则

**可叠加** (效果翻倍):
- 悬念钩 + 情绪钩 (疑问+心动同时存在)
- 反转钩 + 危机钩 (反转带来的危机)
- 信息钩 + 悬念钩 (信息引出更大疑问)
- 危机钩 + 情绪钩 (危险中的情感抉择)

**不建议叠加**:
- 反转钩 + 反转钩
- 信息钩 + 信息钩
- 三种以上叠加

### 我们的钩子分配 (季 1)

| EP | 钩子类型 | 子模式 | 钩子文本 (示例) |
|---|---|---|---|
| 01 | 悬念钩 | 来者悬念 | "客厅尽头那个最大的纸箱, 突然动了一下" |
| 02 | 情绪钩 | 甜蜜中断 | "我闭上眼, 背后传来轻轻的呼噜——突然, 一只爪子踩在我肚子上" |
| 03 | 信息钩 | 线索揭露 | "YouKei 盯着窗外那个移动的小黑点, 第一次发出 '咔咔' 声" |
| 04 | 反转钩 | 动机反转 | "沙发下那个湿湿的东西, 不是水, 是鱼——我以为它在玩, 其实它在藏" |
| 05 | 悬念钩 | 结果悬念 | "主人抹脸时, 突然发现 YouKei 已经跳到书房键盘上 — EP06 预告" |
| 06 | 情绪钩 | 心碎中断 | "邮件发出去了, 收件人是 CEO, 主题 '喵喵喵' — 老板的脸凝固了" |
| 07 | 信息钩 | 证据揭露 | "YouKei 盯着楼下那只狗, 突然扭头看我 — 它在想什么?" |
| 08 | 反转钩 | 身份反转 | "朋友一直打喷嚏, 突然不打了 — YouKei 蹭了他一脸口水, 他居然笑了" |
| 09 | 危机钩 | 突袭 | "电梯门开了, 迎面是一只金毛 — YouKei 在猫包里疯狂挣扎" |
| 10 | 反转钩 | 局势反转 | "拍了 100 张, 全是糊的; 删掉相机的瞬间, YouKei 突然坐下看镜头" |
| 11 | 危机钩 | 暴露 | "半夜 3 点, YouKei 打喷嚏了 — 我打开手机, 跳出来 12 个搜索结果: '猫打喷嚏会死吗'" |
| 12 | (无) | (圆满收束) | — |

### 钩子质量自检

| 检查项 | 标准 |
|---|---|
| 有未回答的问题吗? | 至少 1 个 |
| 情绪到位了吗? | 观众结尾时情绪高位 |
| 切断时机对吗? | 最关键一刻戛然而止 |
| 和下一集衔接吗? | 下集开头自然承接 |
| 钩子和主线相关吗? | 不是无关紧要的小事 |
| 是否重复了? | 连续 3 集不用同类型 |

### 我们的用法

- **Writer 注入**: 全部 EP 必注入本文件
- **季弧设计**: `season-01.json` 给每集指定 `hook_type` 和 `hook_subtype`

## 4️⃣ satisfaction-matrix.md (爽点矩阵)

### 5 大爽点

| 类型 | 一句话 | 萌宠剧主占比 |
|---|---|---|
| ① **身份碾压** | 被看不起的人亮出真实身份, 全场震惊 | 5% (极罕见) |
| ② **打脸复仇** | 以彼之道还施彼身 | 10% (猫的本能胜利) |
| ③ **逆袭翻盘** | 从谷底绝地反弹 | 5% (罕见) |
| ④ **情感爆发** | 压抑已久的情感突然释放 | **60%** (萌宠剧核心) |
| ⑤ **悬念揭秘** | 困扰已久的谜题终于揭晓 | 20% (副线) |

### 情绪公式

- **身份碾压**: 轻视 → 蓄力 → 揭露 → 碾压 → 跪地求饶
- **打脸复仇**: 被欺负 → 隐忍 → 反击 → 恶人当众出丑
- **逆袭翻盘**: 跌入谷底 → 绝望 → 转机 → 一步步翻盘 → 巅峰
- **情感爆发**: 误会/压抑 → 情感积累 → 爆发/告白/和解
- **悬念揭秘**: 谜题建立 → 线索积累 → 真相逼近 → 揭秘 → 震惊

### 爽点分布策略 (萌宠适配)

| 阶段 | 密度 | 强度 | 推荐类型 |
|---|---|---|---|
| 起势 (EP01-02) | 每集 | ★★ | 情感爆发 (小甜/萌点) |
| 攀升 (EP03-06) | 每 2 集 | ★★★ | 情感爆发 + 悬念揭秘 + 打脸 |
| 风暴 (EP07-10) | 每集 | ★★★★ | 全类型交替 |
| 决战 (EP11-12) | 每集 | ★★★★★ | 终极情感爆发 |

### 我们的爽点分配 (季 1)

| EP | 主爽点 | 强度 | 描述 |
|---|---|---|---|
| 01 | 情感爆发 | ★★★ | 萌点 (猫钻箱子) |
| 02 | 情感爆发 | ★★★★ | 萌点 (半夜踩肚子) |
| 03 | 悬念揭秘 | ★★★ | 猫第一次看鸟, "咔咔"声 |
| 04 | 打脸复仇 | ★★★ | 猫偷鱼藏起来, 主人哭笑不得 |
| 05 | 情感爆发 + 悬念揭秘 | ★★★★ | 萌点 (泡沫猫) + 揭秘 (洗澡真相) |

| 08 | 反转钩 (打脸 + 情感爆发) | ★★★★ | 朋友打喷嚏 → 猫反蹭 → 朋友笑 |

## 5️⃣ villain-design.md (4 层反派体系)

### 短剧 4 层反派

| 层级 | 定位 | 活跃时段 |
|---|---|---|
| 第一层 | 小反派·日常对抗 | 前 1/4 |
| 第二层 | 中反派·阶段威胁 | 前 2/3 |
| 第三层 | 大反派·核心对抗 | 中后期 |
| 第四层 | 隐藏反派·终极反转 | 后 1/3 揭露 |

### 萌宠剧简化适配

萌宠剧没有真反派,但可以转化为**"日常小麻烦"**:

| 层级 | 萌宠剧对应 | 示例 |
|---|---|---|
| 第一层 | 猫的本能 | 半夜蹦迪 / 偷鱼 / 抓沙发 |
| 第二层 | 现实问题 | 没食物 / 打雷 / 生病 / 朋友过敏 |
| 第三层 | 主人的情绪 | 加班熬夜 / 想独处 / 拍照失败 |
| 第四层 | (隐藏反派 — 罕见) | 主人发现自己也对猫过敏 (反转) |

### 我们的用法

- **萌宠剧不严格用 4 层**,但 EP04/EP08/EP09/EP11 可以借用"小反派"思路
- **Writer 注入**: 可选, 默认不注入 (避免污染萌宠基调)

### 萌宠剧 (新增题材)

虽然 short-drama 没有"萌宠日常"题材,但我们可以从以下借鉴:

| short-drama 题材 | 萌宠适配元素 |
|---|---|
| 萌宝 (最接近) | 萌点密度 / 日常向 / 角色成长 |
| 甜宠 (辅助) | 主人对猫的宠溺视角 |
| 都市 (辅助) | 上海 60 平 + 现代生活背景 |

### 我们的用法

- **Writer 注入**: 仅作为 "萌宠日常 = 萌宝+甜宠+都市" 题材参考, 注入精简版
- **避免污染**: 不用 "战神归来 / 重生穿越 / 宫斗" 等强戏剧题材的描写风格

## 7️⃣ paywall-design.md (付费卡点)

### 我们是否需要?

❌ **我们不做付费墙** (博客免费)

### 借鉴什么?

✅ **"卡点集 = 最强钩子"** 的设计思路可以借鉴:

- 我们的"风暴段 EP07-10" = 卡点集 (钩子最强)
- 我们的"决战段 EP11-12" = 终极卡点 (EP11 危机钩最强, EP12 无钩子收束)

### 我们的用法

- **不直接注入**,但用于季弧设计时的钩子强度分配

## 8️⃣ compliance-checklist.md (合规审核)

### 短剧合规 4 维度

1. 红线检测 (政治/违法/色情/暴力/歧视)
2. 高风险内容 (未成年人/宗教民族/历史/医疗法律)
3. 正能量校验 (价值观/社会影响)
4. 广告植入 (软广合规)

### 萌宠剧合规简化

| 维度 | 我们是否需要 |
|---|---|
| 红线 | ✅ 自动检测 (极少触发) |
| 高风险 | ⚠️ 简化为"避免让猫做危险动作" |
| 正能量 | ✅ 萌宠自带正能量 |
| 广告植入 | ❌ 不做 |

### 我们的用法

- **Critic 合规审查**: 评分体系第 5 维 "格式" 内检查
- **Writer 注入**: 可选 (避免"宠物拟人化血腥"/"虐待动物"等)
